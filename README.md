# larch-zhenji-art

Larch 視覺小說《洛泉．袁真跡》五卷用到的 CG。這裡只放圖，產線與劇本在私有的 larch-taoyuan。

Larch 的卡片經 jsDelivr 取用這裡的圖：

    https://cdn.jsdelivr.net/gh/yazelin/larch-zhenji-art@main/cg/<檔名>

檔名後面那段是內容雜湊（例：`v3_tsy_box.1a2b3c4d.webp`）。jsDelivr 會把同一個網址快取七天，換圖時換檔名，玩家才看得到新圖。
`cg/manifest.json` 記遊戲裡的檔名對到這裡的哪一個檔。

圖是產生出來的，不要直接在這裡改；換圖從 larch-taoyuan 重新同步（`zhenji/art_sync.py`）。

史料考證與原聲帶在 [larch-zhenji-canon](https://yazelin.github.io/larch-zhenji-canon/)。
